# Полихроний — Держава Палеологов (1261–1347)

Пошаговая стратегия в браузере в духе Knights of Honor: Византия от возвращения Константинополя до Чёрной смерти.

**Играть:** https://craidenx.github.io/Polychronion/

- Карта с 34 областями (владелец, доход, гарнизон, укрепления, настроение), прокрутка и масштаб.
- Совет из 7 героев: полководцы, купцы, наместники, священники, шпионы, дипломаты — с уровнями, навыками, чертами, изменами и пленом.
- Вкладка «Государство»: налоги, порча монеты, законы, уния с Римом, флот, стройки, наследник и регентство.
- Ход — сезон. Осады длятся несколько ходов; штурм и полевые сражения открывают отдельный экран боя (пошаговый, с рельефом). Есть «Рассчитать автоматически».
- Исторические события 1261–1347 с выбором; финал — Чёрная смерть, оценка правления и эпилоги.
- Сохранение в браузере.

Файлы: `index.html` (вся игра, без внешних библиотек) и `map.png` (карта; политические цвета убраны — владельцев игра рисует сама).
Модуль боя (`Battle` внутри файла) отделён от логики ходов: вход — две армии, местность, полководцы; выход — победитель и потери.
