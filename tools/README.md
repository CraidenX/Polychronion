# Сборка карты и игры

Игра — один файл `../index.html` плюс фон `../map.png`. Их собирают из частей в `src/` и карт автора.

Карты автора (PNG без сжатия, одного размера) лежат в `../source/`:
- `*political*.png` — державы 1261 года (цвет = держава), тёмные линии — границы регионов, светлые — провинций;
- `*regions*.png` — регионы, каждый своим цветом; светлые линии (223,223,223) внутри — провинции; чисто белый (255,255,255) — игровые горы, серые — горы-фон за пределами карты.

Порядок сборки (Python 3 + numpy + Pillow; Node — для проверки):
1. `python3 regseg3.py` — регионы (цвет) и провинции (светлые линии; правило островов: мелкие острова региона — одна провинция, если между ними нет белой черточки; остров крупнее ~450 км² — своя провинция) → `umap/`.
2. `python3 mkadj.py` — связи регионов с учётом гор: коричневый хребет закрывает путь, перевал (пунктир #FF00FF) открывает → `umap/adj.json`, `umap/passes.json`.
3. `python3 mkgen2.py` — игровые области, владельцы (таблица `FMAP`), связи, названия регионов из `names.json` → `gen.json`, `mapinfo3.json`.
4. `python3 mkprov.py ..` — `../ids.png` (номер провинции в цвете пикселя, вполовину разрешения) и список провинций.
4а. `python3 mkrivers.py` — малые реки с карты мода (`source/mod - реки.png`): совмещение по морю (сдвиг 34 px), берега рек (#000020) на суше автора → заливка русла → осевая линия → река ровной ширины; устья дотягиваются до воды, оторванные убираются → `umap/rivers.npy`. Судоходные (большие) реки автор рисует сам на своих картах цветом воды.
4б. `python3 mkforest.py` — леса по исторической географии XIII века (зоны с плотностью в самом скрипте: Шумадия, Кодрии Влэсией, Телеорман, Понт, Колхида и др.), предгорья гуще, гребни и пустыни без леса → `umap/forest.npy`, `umap/conifer.npy` (хвойные у гор).
4в. `python3 mkterrain.py ПАПКА` — местность (цвет земли, тип местности, высоты) из эталонной карты в нашей сетке → `terrain/` (готовые вырезки уже лежат там; шаг нужен, только если эталон сменится).
5. `python3 mkmap3.py ..` — фон `../map.jpg` (зерно суши, глубина моря, рельеф под горами и рисованные пики по хребтам — `peaks.py`) и широкая маска гор в синем канале `../ids.png`; затем `python3 mkvec.py ..` — векторные границы `../borders.js`.
5а. `python3 mkwater.py ..` — акварельная подложка `../map_wc.jpg` и плитки `../hi_wc/` (стиль по скрипту автора `experiments/wcmap.py`; цвет местности из эталона, акварельные леса и горы, море со штрихами волн). В игре стиль выбирается в меню.
5б. `python3 mkclouds.py ..` — атлас облаков `../clouds.png` (16 объёмных пористых облаков; в игре облако собирается из 2–4 штук). Деревья акварели — готовые рисунки из `trees.py`.
5в. `python3 mkseamask.py ..` — маска открытого моря `../sea.png` (без рек и озёр) для анимации воды и `../foam.png` — данные прибоя: расстояние до берега со знаком (у маленьких островов полоса уже), направление берега, открытость; волны идут по ветру — наветренные берега получают сильный прибой, подветренные слабый. Ноль расстояния — под серединой нарисованного контура берега. В игре по этим данным каждый кадр считается прибой «как в Героях»: тонкая пенная кромка и удары волн — у каждого участка берега (ячейки) свои, в своё время; волна подходит, белая вода заходит на контур берега, пена тает.
   `python3 mksounds.py ..` — звуки моря `../sounds/` (волны, чайки, плеск о камни) из свободных записей OpenGameArt и Wikimedia Commons (CC0 и общественное достояние; список — `../sounds/CREDITS.txt`). Исходники скачиваются в `sounds_src/` (в репозиторий не кладутся). Играет их модуль SEASND в `src/6_ui.js`.
   `experiments/water_motion.js` — эксперимент: варианты «живой» поверхности моря на WebGL (течение, зыбь, порывы ветра, блики), в игру пока не встроен.
6. `python3 mkpadj.py` — граф соседства провинций для движения войск (суша, перевалы, проливы, море) → `umap/padj.json` и `mapinfo3.json`.
7. `python3 mkroads.py ..` — дороги по местности для каждой связи провинций (поиск пути по сетке 3×3 px: хребты непроходимы, кроме перевалов; по морю — только по воде) → `../roads.js`. Морские связи без пути по воде убираются из графа.
8. `python3 build.py ../index.html mapinfo3.json gen.json` — сборка игры; номер версии (число коммитов + 1) и дата пишутся в игру и в `../version.json` — по нему игра сообщает, что на сайте вышла новая версия.
9. `node sim.js 4 smart` — автоматические партии для проверки.

`islands.json` — острова-провинции: остров из списка (или крупнее ~450 км²) — отдельная провинция, остальные мелкие острова присоединяются к ближайшей провинции своего региона.
`fmap.py` — цвет на политической карте → держава.
`merge.json` — явные объединения регионов (одинаковый цвет далеко друг от друга).
`fixes.json` — ручные поправки провинций: кусок в точке from отдать провинции в точке to.
`names.json` — названия регионов: цвет на карте регионов + примерные координаты → название. Правится вручную.
Незакрашенные на карте регионов земли временно заполняются старыми областями (Вороной), чтобы работали исторические события.
`umap/fit.json` — проекция карты (равнопромежуточная, подобрана по береговым линиям).
Новый цвет державы на политической карте нужно добавить в `FMAP` в `mkgen2.py`.
