# Сборка карты и игры

Игра — один файл `../index.html`. Его собирают из частей в `src/` и данных карты.

Исходные карты автора лежат в `../source/`:
- `states.*` — державы 1261 года (цвет = держава);
- `regions.*` — регионы (каждый своим цветом), белые линии внутри — провинции.

Порядок сборки (Python 3 + numpy + Pillow, Node для проверки):
1. Скопировать `../source/states.*` в `umap/src.webp`, `../source/regions.*` в `umap/regions.webp`.
2. `python3 mkmap2.py <папка>` — фоновая карта `map.png` (политические цвета убраны) и проекция.
3. `python3 regseg.py` — разбор регионов и провинций.
4. `python3 mkgen.py` — игровые регионы, владельцы, связи → `gen.json`, `mapinfo3.json`.
5. `python3 build.py ../index.html mapinfo3.json gen.json` — сборка игры.
6. `node sim.js 4 smart` — автоматические партии для проверки баланса.

`umap/fit.json` — подобранная проекция (равнопромежуточная, ≈51 px/° для исходника 2000×1094).
Для карты другого размера её нужно пересчитать (`fit.py`, нужны береговые линии Natural Earth в `ne/`).
